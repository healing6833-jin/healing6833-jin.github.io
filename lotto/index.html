사용법

1. 운세 카드를 한 장 골라요.

조합 수를 1개, 3개, 5개 중 고른 뒤 뒤집힌 카드 한 장을 누르세요. 카드는 무작위로 섞여 있고, 카드의 위치나 그림으로 결과를 알 수 없어요.

2. 자동으로 나온 번호를 확인해요.

카드의 운세 숫자 하나가 각 조합에 들어가고, 나머지 다섯 개는 무작위로 채워져요. 다른 운세를 보고 싶으면 새 카드 섞기를 누르고 한 장을 다시 고르세요. 운세는 재미로 즐기는 콘텐츠예요.

3. 실제 당첨 확률과 조합 통계를 구분해요.

실제 당첨 확률은 번호 한 조합을 기준으로 표시해요. 결과 위의 여러 조합 1등 확률은 같은 회차에 표시된 서로 다른 조합을 모두 사용한다고 가정해요. 조합을 눌러 보는 홀짝·합계 통계는 숫자의 구성이지 당첨 가능성이 아니에요.

4. 번호를 복사하거나 보관해요.

전체 복사로 생성한 번호를 메모장에 붙여넣을 수 있어요. 조합 보관을 누른 결과만 이 브라우저에 최대 20건 남아요. 다른 기기로 옮겨지지 않으며 브라우저 데이터를 지우면 사라져요.

오늘의 행운번호 당첨을 예측하거나 복권을 판매하지 않아요.
