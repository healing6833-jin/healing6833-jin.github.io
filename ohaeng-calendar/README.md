# 훼이맵 월간 오행 달력

매달 말일에 다음 달 달력(`YYYY-MM.png`, 2160×2700)을 이 폴더에 저장합니다.
날짜별 일진(간지)·오행·추천 오일은 텔레그램 매일 아침 글과 같은 규칙으로 계산하고,
저장 전 만세력(lunar_python)과 하루씩 대조합니다.
날짜 옆 작은 숫자는 한국천문연구원 기준 음력(korean-lunar-calendar)입니다.

고객 생일을 표시한 **사장님용 달력은 개인정보라 이 저장소에 올리지 않습니다.**
(`tool/make.ts --births 고객.json --out 저장소-밖-경로.png` 로 만들어 사장님께만 전달)
